# BotFitnessByR

Sistema inteligente de recomendación de rutinas funcionales usando IA.

## Tecnologías utilizadas
- Python
- Telegram Bot API
- SQLite
- Pandas
- Scikit-learn
- Random Forest
- Decision Tree

## Funciones
- Login y registro
- Rutinas personalizadas
- Restricciones médicas
- Perfil persistente
- IA para clasificación de rutinas
- Menús interactivos
- Limpieza automática de mensajes
